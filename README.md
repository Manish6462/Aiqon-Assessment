# Shipment ETA & Delay Propagation Prediction System

## Overview
An end-to-end AI system that predicts shipment **Estimated Time of Arrival (ETA)** and models how delays propagate across multiple stages of the shipment lifecycle. Built using the **Brazilian E-Commerce (Olist)** real-world dataset (~95K delivered shipments).

## Problem Statement
In global logistics, delays at one stage (order processing → seller preparation → carrier transit) often cascade downstream and amplify final delivery time. This system:
1. **Predicts final ETA** (total delivery hours) using an XGBoost Regressor
2. **Classifies delay likelihood** (binary: delayed / on-time) using an XGBoost Classifier
3. **Explains predictions** using SHAP values — identifying which stage or route factor drives each delay

## Dataset
**Brazilian E-Commerce Public Dataset by Olist** (Kaggle)
- ~96K delivered orders with complete multi-stage timestamps (2016–2018)
- Real seller/customer locations across 27 Brazilian states
- Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

> **Note:** Download the Olist CSV files from Kaggle and place them in `data/` before running.

## Shipment Stages Modeled
```
Purchase → Approval → Carrier Handoff → Customer Delivery
 (Stage 1)   (Stage 2)    (Stage 3: Transit)
```

## Key Features
- **Delay Propagation Features**: Cumulative delays, stage excess deviations, cascade interaction (`stage1_x_stage2_interaction`)
- **Route Intelligence**: Historical route performance per seller-state → customer-state corridor, seller reliability scores
- **Temporal Patterns**: Day-of-week, hour, month, weekend effects
- **Geographic Features**: Haversine seller-to-customer distance, same-state flag

## Setup & Run

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Place Olist CSV files in data/ directory
#    Download from: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

# 3. Run the complete training & evaluation pipeline
python main.py

# 4. Run interactive CLI demo (predictions, SHAP explanations, what-if cascade)
python demo.py

# 5. (Optional) Rebuild the 3-page publication PDF report
python generate_pdf_report.py
```
